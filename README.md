## 🚀 Características del Proyecto

La aplicación ha sido diseñada e implementada bajo los estándares web solicitados en la guía práctica:

* **HTML5 Semántico:** Estructuración limpia mediante etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer()`) que favorecen la accesibilidad y la compatibilidad con tecnologías de asistencia.
* **Formulario Integrado:** Formulario estructurado con validación nativa del navegador mediante atributos HTML5 estándar como `required`, `min` y `max`.
* **CSS3 Responsivo (Mobile-First):** Layout principal maquetado mediante **CSS Grid** y componentes estructurados con **Flexbox**. Incluye variables CSS personalizadas y soporte para Modo Oscuro mediante la directiva `prefers-color-scheme`.
* **JavaScript ES6+ Asíncrono:** Modularización del código (`import`/`export`) para la manipulación del DOM y el consumo dinámico de datos de la API pública **JSONPlaceholder** utilizando `fetch` y `async/await`.
